# 2026 年 8 月事件台账 · 匹配性报告

> **这份报告回答一个问题：这些事件符合口径定义吗。**
> 「符合」不是一句话 —— 每一行都要能说出：命中哪条正面判据、排除了哪几条反证、依据是哪句原文。

## 一、判定链（本报告用的那一套）

按顺序走四步，**任一步得出结果即停止**：

| 步 | 判断 | 结果 |
|---|---|---|
| 0 | **硬门槛**：实施主体是否为国家／政府力量 | 是 → 不计入 |
| 1 | **反证 N1–N6**：私人纠纷 / 索取财物 / 事故 / 双方已交战 / 反恐执法本身 / 汇总条目 | 命中任一 → 不计入 |
| 2 | **正面判据 P1–P7**：命中任一 | 计入 |
| 3 | **兜底**：以上均不命中 | 不计入 |

**判据速查**（首次出现处给完整说明，后文只用编号）：

| 编号 | 内容 |
|---|---|
| P1 | 主体属被认定的恐怖组织／分子，且有证据表明本事件由其实施 |
| P1b | 组织公开宣称负责 |
| P3 | 目标为政府、军警、公共设施或国家象征（军警须为当时非战斗状态） |
| P4 | 冲突区对平民聚居社区的无差别暴力 |
| P7 | 有伤亡的武装暴力，非私人、非索财、非事故、非反恐战果 |
| N1 | 私人纠纷、家族仇杀、土地／水源争端 |
| N2 | 以索取财物为目的（绑架索赎、抢劫） |
| N3 | 事故、误操作、非故意事件 |
| N4 | 双方均已进入交战状态、目标非「非战斗状态」 |
| N5 | 反恐行动及执法行动本身 |
| N6 | 汇总、统计或重复条目 |

## 三、几条需要单独说明的判定

### ① 也门 8·6 政府军营地 30 死 —— 不计入（反证 N4）

原文：`Yemen's Houthi group has killed at least 30 government soldiers and injured 15 others in missile attacks on Yemeni military camps`

虽然日期确为 08-06、数字也明确，但**胡塞与也门政府军处于长期内战交战状态**，
袭击军营属双方交战行动，命中反证 N4（目标非「非战斗状态」）。
**这条不放进来，这个判断比放进来更重要** —— 它说明口径在起作用，不是"见到袭击就收"。

### ② 尼日利亚 8·10 凯比州交火 —— 计入，但只计受害方

原文：`At least 10 police officers, 17 'bandits' and two civilians have been killed`

警方同时击毙 17 名匪徒。按口径「击毙袭击者不计入死亡（那是战果不是受害者）」，
**死亡只记受害方 12 人（10 警 + 2 平民），不含被击毙的 17 名匪徒**。
这是口径里最容易算错的一处。

### ③ 泰国 8·22 协同纵火 —— 计入，虽无死亡

原文：`Dozens of coordinated arson ... left at least three people wounded`

死亡 0、受伤 3。按 P3（政府办公楼、商铺、电信塔）+ 「受伤≥3」门槛，**计入**。
有些人会以为"没死人就不算"，判据里没有这条要求。

### ④ 哥伦比亚 8·01 库库塔 —— 计入，死亡 0

受伤 14（11 警 + 3 平民），达「受伤≥3」门槛。同理计入。

## 四、三条口径待裁定的（子代理明确标出，不擅自决定）

这三条本报告按现行判据判为**计入**，但**都可能被评审方推翻**，逐条列出供裁定：

### #11 阿富汗法扎巴德 —— 受害者是塔利班政权官员

- 事实：巴达赫尚省行政首长（报道用 mayor）车内爆炸身亡，1 死，无受伤数。
- 争议：受害者是**执政当局官员**。P3 的适用范围是「政府、军警、公共设施或国家象征」，
  塔利班官员属政府人员，故 P3 成立；但若评审方认为「反政府武装打死执政者」属叛乱/内战
  而非恐袭，则应落 N4。
- 本库判：**计入，置信度 C**（要素弱）。**若要求严格，此条可移出。**

### #12 尼日利亚高原州 —— 农牧民族群报复背景，未点名组织

- 事实：逐户砍刀屠杀村民，妇孺为主，25 死。
- 争议：报道提到「农民与牧民的紧张关系」，属**族群/资源冲突背景**；且未点名任何恐怖组织。
- 本库判：**计入**。理由：P3 不要求主体识别（这正是补 P3 的原因）；
  且判据看**形态**（有组织武装暴力 + 明确受害对象 + 无索财）而非**诱因**（土地争端）。
- **但这条最可能被推翻**：若评审方把农牧冲突整体归为「社群暴力」而非恐袭，应移出。

### #14 海地肯斯科夫 —— 帮派暴力是否计入恐袭

- 事实：武装帮派夜袭社区，47 死、22 伤、绑架 50 余人、焚烧民居。
- 争议：海地帮派通常按**有组织犯罪**处理，是否算「恐怖袭击」取决于是否认定其有政治目的。
- 本库判：**计入**。理由：大规模杀人 + 绑架 + 纵火，属 P3 有组织武装暴力；
  本库口径不要求证明政治目的（教师 5+2 中「与政治目的紧密相关」在本库由 P1/P3/P4 承载）。
- **若评审方要求帮派暴力单列，此条应移出主台账。**

> **这三条的处理原则**：不藏、不擅自扩大、也不擅自删除。列在这里，由委托方裁定。
> 台账里已按「计入」处理并标注存疑，若裁定移出，删行后重跑数字门禁即可。

## 五、与委托方标准的逐条对照

| 委托方标准原文 | 本库怎么操作化 | 对应判据 |
|---|---|---|
| 主体非国家行为体 | 硬门槛：国家/政府力量直接排除 | 步 0 |
| 主观故意、意图造成严重社会危害 | 排除事故（N3）；要求明确受害对象 | P3 / P4 / P7 |
| 使用暴力或以暴力相威胁 | 纯言论、宣传、资助不构成事件 | 全部判据的前置条件 |
| 与政治目的紧密相关 | 排除私人纠纷（N1）、索取财物（N2） | P1 / P3 / P4 |
| 对象为平民或非战斗状态军警 | 军警须为当时非战斗状态 | P3 / P4 |
| +1 主体属认定的恐怖组织或分子 | 径行命中 | P1 |
| +2 事发地政府直接认定该事件 | 径行命中，「正在调查」不算 | P5 |

**7 条原文全部落到具体判据，无悬空条款。**
