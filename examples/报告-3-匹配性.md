# 2026 年 8 月事件台账 · 匹配性报告

> **这份报告回答一个问题：这些事件符合口径定义吗。**
> 「符合」不是一句话，而是每一行都能说出：命中了哪条正面判据、排除了哪几条反证、
> 关键依据是哪句原文。

## 一、判定链（本报告用的那一套）

判定一条事件按顺序走四步，**任何一步得出结果就停止**：

| 步 | 判断 | 结果 |
|---|---|---|
| 0 | **硬门槛**：实施主体是否为国家／政府力量 | 是 → 不计入 |
| 1 | **反证 N1–N6**：私人纠纷 / 索取财物 / 事故 / 双方已交战 / 反恐执法本身 / 汇总条目 | 命中任一 → 不计入 |
| 2 | **正面判据 P1–P7**：命中任一 | 计入 |
| 3 | **兜底**：以上均不命中 | 不计入 |

**判据速查**（首次出现的完整说明，后文只用编号）：

| 编号 | 内容 |
|---|---|
| P1 | 主体属被认定的恐怖组织／分子，且有证据表明本事件由其实施 |
| P1b | 组织公开宣称负责 |
| P2 | 目标为特定族群／宗教／教派群体 |
| P3 | 目标为政府、军警、公共设施或国家象征（军警须为当时非战斗状态） |
| P4 | 冲突区对平民聚居社区的无差别暴力 |
| P5 | 事发地国政府就该起事件明确认定为恐袭 |
| P6 | 同一主体同期对同类目标实施系列袭击 |
| P7 | 有伤亡的武装暴力，且非私人、非索财、非事故、非反恐战果 |
| N1 | 私人纠纷、家族仇杀、土地／水源争端 |
| N2 | 以索取财物为目的（绑架索赎、抢劫、勒索） |
| N3 | 事故、误操作、非故意事件 |
| N4 | 双方均已进入交战状态、目标非「非战斗状态」 |
| N5 | 反恐行动及执法行动本身 |
| N6 | 汇总、统计或重复条目 |

## 二、逐条判定

### 行 2 · 也门 · 8·6 · 胡塞袭击政府军营地

| 步 | 判断 | 依据 |
|---|---|---|
| 硬门槛 | 通过 | 实施主体为胡塞武装（非国家行为体） |
| N1 私人纠纷 | 不成立 | 无纠纷线索 |
| N2 索财 | 不成立 | 无索赎、抢劫线索 |
| N3 事故 | 不成立 | 明确为武装袭击 |
| N4 已交战状态 | **存疑 → 暂判不成立** | 目标是「政府军营地」，属军事设施；但报道未说明营地是否处于战斗状态 |
| N5 反恐战果 | 不成立 | 非执法行动 |
| N6 汇总条目 | 不成立 | 单起协同袭击 |
| **P3** | **命中** | 目标是政府军事设施与国家象征 |
| **P1b** | **命中** | 胡塞方对袭击结果作了公开宣称 |
| 结论 | **计入** | 双判据命中 |

> **软肋**：N4 存疑。若查实双方已在交战状态，此条应改判不计入。已列入「争议条目」。

### 行 3 · 尼日利亚 · 8·18 · 高原州社区遇袭

| 步 | 判断 | 依据 |
|---|---|---|
| 硬门槛 | 通过 | 实施者为不明武装分子 |
| N1 私人纠纷 | **存疑** | 报道提到「农民与牧民之间的紧张关系」，属社群冲突背景；但袭击形态是有组织武装扫射，非个别仇杀 |
| N2 索财 | 不成立 | 无索赎线索 |
| N3 事故 | 不成立 | — |
| N4 已交战状态 | 不成立 | 受害者是社区居民 |
| N5 反恐战果 | 不成立 | — |
| N6 汇总条目 | 不成立 | 单起事件 |
| **P3** | **命中** | 目标是平民社区（按 P4 亦成立） |
| **P4** | **命中** | 高发区内对平民聚居社区的无差别暴力 |
| 结论 | **计入** | |

> **软肋**：N1 与 P4 存在张力 —— 农民牧民冲突有时被归为「资源争夺」。本库判据是
> 「有组织武装暴力 + 明确受害对象 + 无索财」即倾向计入，把背景冲突当作诱因而非性质。
> 这个判断可能被推翻，已列入「争议条目」。

### 行 4 · 刚果（金）· 8·22 · 伊图里省两村庄

| 步 | 判断 | 依据 |
|---|---|---|
| 硬门槛 | 通过 | 疑为 ADF（与伊斯兰国有关联的民兵） |
| N1 / N2 / N3 | 均不成立 | 无纠纷、无索财、非事故 |
| N4 | 不成立 | 受害者是村民 |
| N5 | 不成立 | — |
| N6 汇总条目 | 不成立 | 两处村庄属同一次行动的相邻现场，按「同一组织同一时段相邻现场」计一条 |
| **P3** | **命中** | 平民村庄 |
| **P1** | **部分命中** | ADF 在联合国名单内；但报道用「疑似」，主体未最终确认 |
| 结论 | **计入**（置信度 B） | |

> **软肋**：主体是「疑似 ADF」。按判据，主体未确认不影响 P3/P4 命中 —— 这正是
> 不把「主体识别」写进判据的原因。但若后续查明是其他武装，应改组织名而非改判定。

## 四、与委托方标准的逐条对照

| 委托方标准原文 | 本库怎么操作化 | 对应判据 |
|---|---|---|
| 主体非国家行为体 | 硬门槛：国家/政府力量直接排除 | 步 0 |
| 主观故意、意图造成严重社会危害 | 排除事故（N3）；要求有明确受害对象 | P2 / P4 / P7 |
| 使用暴力或以暴力相威胁 | 纯言论、宣传、资助不构成事件 | 全部判据的前置条件 |
| 与政治目的紧密相关 | 排除私人纠纷（N1）、索取财物（N2） | P1 / P3 / P4 |
| 对象为平民或非战斗状态军警 | 军警须为当时非战斗状态 | P2 / P3 / P4 |
| +1 主体属认定的恐怖组织或分子 | 径行命中，免核其余要件 | P1 |
| +2 事发地政府直接认定该事件 | 径行命中，「正在调查」不算 | P5 |

**没有悬空条款**：7 条原文全部落到了具体判据上。

## 五、争议与边界（这一节最该被追问）

1. **也门 8·6 的 N4**：袭击军事设施是否算「已交战状态」？本库按「营地平时状态」判，
   倾向计入。若评审方要求严格按交战状态排除，此条应移出。
2. **尼日利亚 8·18 的 N1**：农民牧民冲突算私人纠纷还是恐袭？本库判据是看**形态**
   （有组织武装暴力）而非**诱因**（土地争端）。这是口径选择，不是事实判断。
3. **刚果金 8·22 的两村庄合并**：Mabakuha 与 Amani 相距未公布。本轮按「同一次行动
   相邻现场」计一条。若两村相距超过 15 公里且无共同宣称，应拆成两条。
4. **被排除的新华网那条**：其披露的「被挫败的袭击企图」本该另建记录，本轮因原文要素
   不足（无受害对象与伤亡）未建，落兜底。这是**漏建**，不是判错。

> 排除 1 起（反证 N5 反恐战果）。委托方标准 7 条已逐条操作化，无悬空条款。
> 争议 4 条，均在第五节列明，其中 2 条存在被推翻的可能。
