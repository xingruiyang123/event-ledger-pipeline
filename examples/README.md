# 示例：2026 年 8 月台账（真实检索产物，非造数）

这个目录是**用本 skill 真实跑出来的完整交付包**。
月份故意选 8 月（不是开发时用的 7 月），用来证明「换个月份也能跑通」。

## 数据从哪来

138 组检索查询 → 809 个唯一候选 URL → 47 篇逐篇抓正文核验 → 确信 18 条属 2026-08
→ 按口径计入 **17 起**（1 起因交战状态排除）。

- 日期确证：`article:published_time` / URL 内嵌日期 / 正文日期措辞，三选一以上
- 每条都保留原文原句（见台账「备注」列 `[证据]` 前缀）
- 拦下 6 条日期不符的误命中：其中「尼日利亚塔拉巴州 48 死」标题完全符合，实为 10 月事件

## 怎么复现

```bash
# 1) 起台账（19 列表头）
python scripts/make_ledger.py --template 19列 \
       --rows examples/rows_2026_08.json --out /tmp/台账.xlsx
python scripts/make_ledger.py --check /tmp/台账.xlsx

# 2) 数字对账（17 条：死亡 157 / 受伤 136）
python scripts/gate_number_drift.py /tmp/台账.xlsx --rows 2-18 --expect 157:136

# 3) 起 PPT 并填数（数字从台账算，不手抄）
cp assets/templates/deck-single-file.html /tmp/index.html
python scripts/fill_deck.py --deck /tmp/index.html --from-ledger /tmp/台账.xlsx --out /tmp/index.html
python scripts/gate_single_file.py /tmp/index.html --pages 5
```

## 三个必须知道的边界

1. **不是「8 月全球完整统计」**。萨赫勒三国（马里/布基纳法索/尼日尔）、索马里、莫桑比克
   存在真实覆盖缺口，教师给的 1408 家信源名录也未遍历。遍历性报告第四节已如实写明。
2. **5 条事件原文未给受伤数，按口径记 0，但不等于确认无人受伤**。台账备注逐条标了 `[缺口]`。
3. **3 条口径存疑**（阿富汗官员被害、尼日利亚农牧冲突、海地帮派暴力）已在匹配性报告第四节
   列明，由委托方裁定去留。

## 这个示例顺带演示了什么

- **口径真的在挡人**：也门 8·6 政府军营地 30 死，日期数字都确证，但因属内战交战状态，
  命中反证 N4 被排除 —— 见到袭击就收的台账不会做这个判断。
- **击毙袭击者不算受害者**：尼日利亚凯比州交火，警方击毙 17 名匪徒，死亡只记受害方 12 人。
- **没死人也能计入**：泰国协同纵火 0 死 3 伤、哥伦比亚卡车炸弹 0 死 14 伤，均达「受伤≥3」门槛。
- **URL 标题不等于内容**：巴基斯坦那篇 URL 至今是 `5-killed-...`，正文已更新为 14 killed。
