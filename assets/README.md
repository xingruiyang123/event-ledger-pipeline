# 内置素材

这两份是**默认值**。用户给了自己的信源表和口径，一律用用户的，本目录只作补充。

| 文件 | 内容 | 替换方式 |
|---|---|---|
| `default_registry.xlsx` | 1446 家机构名录 | 改 `信源表` sheet 的 8 个列（机构ID/名称/主域名/类型/所在国/语种/优先级/报道覆盖），脚本按列名匹配 |
| `default_caliber.md` | 《恐怖袭击认定与计数标准》对外说明版，7 节 | 直接改正文。若要换域（比如做事故台账），必须重写第二节「什么算一起」和第三节「什么不算」 |

## 替换后要做的

1. 在本文末尾「变更记录」加一行：日期 + 改了什么 + 为什么。
2. 跑一次 `python tests/run_eval.py` 看口径改动对判定结果的影响（真值集是恐怖袭击口径，
   换域后这份测试集会失效，需要另建）。
3. 若改了信源表，跑 `python scripts/harvest_source_registry.py --registry <新表> --dry-run`
   确认能读出家数与检索式。

## 已知限制

- 信源表 1446 家里，可达性与检索状态是**某次实测的时点快照**，会过期。工具只把它当名录用，
  可达性一律重新测（见 `reference/01-信源表核对.md`）。
- 口径里的 250 米 / 15 公里 / 24 小时是**第一版默认参数**，样本扩大后要重新校准。
