# event-ledger-pipeline

**事件台账全流程**：信源表核对 → 搜集 → 核验 → 清洗 → 分析 → 产出 19 列台账 + 三份专项报告 + 单文件网页 PPT。

给 AI agent 用，也给会用命令行的人用。**零注册、零 API key、可离线。**

---

## 30 秒上手

```bash
# 1) 检查环境（缺什么会给出安装命令）
python scripts/env_check.py --ppt

# 2) 一条命令跑通全流程（自动下载数据源）
python scripts/run_pipeline.py --month 2026-09 --outdir ./out
```

产物在 `./out/`：`03_台账.xlsx`、`报告/报告-1~3-*.md`、`index.html`、`02_需人工判.json`

**实测**：从零开始到 **142 条 19 列台账 + 三份专项报告 + 单文件 PPT**，全链路通过，无需准备任何数据。

## 它解决什么问题

做月度事件台账（恐怖袭击、武装冲突等可计数事件）时，最常见的塌方点：

| 问题 | 后果 | 本 skill 怎么挡 |
|---|---|---|
| 用新闻检索做月度台账 | 只有个位数事件，而某国同月就有 500 起 | 强制用 **UCDP 结构化数据**，实测 2361 条 |
| 用错数据集 | 用候选集查历史月份 → 只有 27 条 | 自动探测版本 + 误用诊断 |
| 把交战/帮派火并当恐袭 | 墨西哥毒枭火并 270 条混进台账 | 判定链含 N2/N4 反证，逐条拦 |
| 行为体被脱敏 | 哥伦比亚 168 条被误计入 | 脱敏条目降级为「需人工判」，不硬猜 |
| 改表时整列丢失 | 全程无报错，交付被退回 | `gate_table_roundtrip` 逐格对比 |
| 内部全绿但量级不可信 | 17 条当成果交出去 | `gate_plausibility` **阻断交付** |
| PPT 带外链 | 断网演示不了 | `gate_single_file` 外链必须为 0 |

## 数据源（关键）

| 要求 | 用什么 | 实测 |
|---|---|---|
| **历史月份**（去年及更早） | **UCDP 正式 GED**（免费 39MB，1989–去年） | 2025-08：2361 条 → 判定后 102–142 条 |
| **今年各月** | **UCDP 累计候选集**（13MB，今年 01→最新月） | 2026-08：1860 条 → 判定后 **158 条** |
| 只看最新一个月 | UCDP 精简候选集（1.6MB） | 2026-09：1984 条 → 142 条 |
| 专题样本 | 公开新闻索引 + 逐源点名 | 维基：仅 8 条（偏欧美） |

> ⚠️ **候选集有两个版本，名字极像，选错会得出「某月只有几十条」的假象：**
> `GEDEvent_v26_0_9.csv`（1.6MB，只含最新在编月）→ 查 2026-08 只有 **27 条**（错）
> `GEDEvent_v26_01_26_09.csv`（13MB，累计版）→ 查 2026-08 有 **1860 条**（对）
> `fetch_ucdp.py` 会自动优先选累计版。

> **两个数据集拼起来的时间覆盖**：正式 GED（1989→去年）+ 累计候选集（今年 01→最近月）
> = **1989 至今，只差最近约一个月**。当月数据要等 UCDP 下一次月度更新。

```bash
python scripts/fetch_ucdp.py --outdir ./数据源            # 自动探测最新版 + 断点续传
python scripts/fetch_ucdp.py --candidate --outdir ./数据源 # 轻量候选集 1.6MB
python scripts/fetch_ucdp.py --check --outdir ./数据源     # 校验已有文件
```

## 脚本清单

| 脚本 | 干什么 |
|---|---|
| `env_check.py` | 环境自检（`--ppt` 把 Chrome 列为必需） |
| `fetch_ucdp.py` | 自动探测版本 + 断点续传下载 + 完整性校验 |
| `harvest_ucdp.py` | 从 UCDP 抽某月（区分正式 GED 与候选集） |
| `harvest_wiki_events.py` | 维基「当前事件」日历提取（兜底/摸底） |
| `harvest_multi_source.py` | 多源叠加采集 |
| `extract_events.py` | 结构化抽取（actor/victim/act/deaths） |
| `filter_war_context.py` | 战争语境分流 |
| `judge_events.py` | **判定链**：计入 / 不计入 / 需人工判 |
| `make_ledger.py` | 19 列台账骨架 + 表头校验 |
| `fill_deck.py` | 把台账数字填进 PPT（不手抄） |
| `gate_plausibility.py` | **量级门禁**（阻断交付） |
| `gate_number_drift.py` | 逐行加总 vs 公布合计 |
| `gate_table_roundtrip.py` | 改表前后逐格对比 |
| `gate_single_file.py` | 单文件离线门禁 |
| `gate_date_published.py` | 发布日期确证 |
| `run_pipeline.py` | 一键串起来 |

## 通用性

- **无本机绝对路径**、无专有工具依赖（回归测试会检查）
- **Python 3.9+**（回归测试用 `feature_version=(3,9)` 校验语法）
- **自动清空代理变量**：很多机器设了 `HTTP_PROXY` 指向没启动的代理，
  会让所有请求失败、看起来像断网。所有脚本内部都会清空，实测有效
- **抓取后端可插拔**：`--fetch-cmd "任意能取网页的命令 {url}"`
- **无需注册**：UCDP 完全免费、无需 API key
- **可离线**：数据下载一次，之后所有月份都能算（实测断网下抽取 2361 条正常）

## 三份专项报告（交付主体）

委托方检查台账时真正会问三句话，一份汇总数字回答不了：

| 报告 | 回答什么 |
|---|---|
| **遍历性** | 该看的信源你都看了吗 |
| **真实性** | 这些事件是真的吗、有没有虚构 |
| **匹配性** | 它们符合口径定义吗、命中哪条判据 |

写法见 `reference/07-三份专项报告.md`；写完按 `reference/08-写作自查.md` 改一遍（自带判据，不依赖外部 skill）。

## 已知边界

1. **102/142 条 ≠ 全球完整统计**，是「UCDP 收录范围内、按本库口径计入」
2. **UCDP 只给死亡不给受伤**，台账「受伤人数」列会是 0
3. **约 28% 条目行为体被脱敏**（`XXX100`），这些标为「需人工判」，不硬猜
4. **正式 GED 滞后约一年**，最新月份数据不全
5. **判定链是恐怖袭击专用**。换做事故台账，反证里的「事故」会把每条都判成不计入 —— 换域必须先重写 S0
