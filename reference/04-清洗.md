# S4 · 清洗（判定、去重、拆并、赋值）

> 这一段产出的是**唯一的台账**。它一旦定稿，后面所有数字都从它复算。

## 一、判定：逐行落链，二值出口

对每一行走 S0 的判定链，并在台账内留痕：

**19 列表里没有「认定通道」「认定结论」「属性标记」这些列，不许加列。**
判定留痕必须塞进已有列，映射如下（照抄这张表，不要自己发明列名）：

| 要留痕的东西 | 写到哪一列 | 格式 |
|---|---|---|
| 命中哪条判据 / 落在哪一步 | **`关联知识点`** | `P3 军警哨所；反证 N1/N2/N4 均不成立` |
| 计入 / 不计入 | **`审核状态`** | 计入→`已确认`；存疑→`待审核`；不计入→`已退回` |
| 未遂 / 组织间冲突 / 归属未确认 等属性 | **`备注`** | 前缀 `[属性]`，如 `[属性]未遂` `[属性]组织间冲突` |
| 不计入的具体理由 | **`备注`** | 前缀 `[排除]`，如 `[排除]M0 国家行为体` `[排除]反证 N2 索财` `[兜底]证据不足` |
| 伤亡区间原始值 | **`备注`** | 前缀 `[区间]`，如 `[区间]原文 27–32 死，采用 27` |

> **不计入的事件不该留在台账里。** 它们另存 `排除清单.xlsx`（同样 19 列），
> 原来那行从主台账删掉。理由：委托方拿到的是「事件台账」，不是「候选清单」。

**表头一列不增不减**（委托方模板硬约束）。本项目提过一次「加一列信源覆盖状态」，被否。

## 二、去重：先认「同一件事」，再数「几条」

按下面顺序判，命中即止：

| 判据 | 判定 |
|---|---|
| 标题/导语关键短语重合 ≥70% | 同一事件，计 1 |
| 发稿时间差 <10 分钟 且 措辞逐句雷同 | **同源改写**（实测有一对只差 18 秒），计 1，且记为同一信息链 |
| 同国、同日、地点相同、伤亡一致 | 同一事件，计 1 |
| 同国、同日、但地点不同或伤亡明显不同 | **分别建 ID**，计 2 |
| 仅「同一组织、时间相近、地点相近」 | **不足以合并**，须有独立关联证据 |

> 这条直接约束置信度 A 档：转载同一通稿的多家媒体**不构成** 2 条独立信息链。

**去重前必做**：把疑似重复分组列成表（组号 / 行号 / 国家日期 / 证据 / 建议动作），
交人工看一遍再执行。本项目 8 组高置信重复涉及 18 行，合并后 84 → 74。

## 三、拆并：按 S0 的计数单位判

执行顺序：**先只读试算**（逐对标注「一起 / 两起 / 判不了」，不改台账）→ 交组内复核
（重点看「判不了」的对子）→ 通过后才动台账。

## 四、清洗时最容易混进来的三类垃圾

| 类 | 表现 | 处理 |
|---|---|---|
| **汇总混入明细** | 一行写「12 小时内两镇遇袭」，实际是另一行 + 一起新事件的汇总 | 改写成明细；或保留为汇总计 0，另建明细。**汇总与明细不得相加** |
| **分析稿当事件** | 「IS 把 IED 作为核心战术」「双连击如何困住安全部队」 | 无具体时间地点 → 不是事件，不计入 |
| **反恐战果当袭击** | 「安全部队清剿击毙 N 名武装分子」 | 反证命中 → 不计入；其中披露的具体袭击**另建记录**独立判定 |

## 五、赋值（每行必须有数）

按 S0 第五节逐行赋值，然后**立刻做三项对账**：

```bash
python scripts/gate_number_drift.py 台账.xlsx --expect 790:238
```

1. **逐行加总 = 公布合计**（不相等就是有行漏赋值或重复计入）
2. **总行数 = 计入条数**（不相等于是有「不计入」的行混在表里）
3. **区间/推算值单列标注**（哪几行是推算、哪几行是下界，报告里要写出来）

**已排除的事件不该占表里的行。** 单独出一份 `已排除清单.xlsx`，写明排除理由与落在哪一步。

## 六、改表的硬技术要点（这块最容易出事故）

| 坑 | 表现 | 处置 |
|---|---|---|
| **整列静默丢失** | 只取字符串字段，数字型单元格返回空 → 整列被写成空白，**全程无报错** | 解析必须同时处理数值型字段；写完**全量逐格回读对比** |
| **只读属性** | 从微信/邮件收到的文件带 444，保存报 not writable | 先 `chmod u+w`；`copy2` 会**传播**只读属性 → 用读写字节的方式复制 |
| **只核行数会漏** | 行数对、某列条数对，但整列已空 | 见 `gate_table_roundtrip.py`：逐格比对，`None` 与 `''` 视为等价 |
| **表头被改动** | 顺手加了一列 | 写数据行只从第 2 行开始，永不碰第 1 行 |

```bash
python scripts/gate_table_roundtrip.py 改前.xlsx 改后.xlsx
```

**这一步不许省。** 本项目出过一次：27 行 × 2 列的年份月份整列被写成空白，
所有自检都通过，是用户一眼看出来的。

## 七、日期与地理

- **日期列只填事发日**；发稿日只作证据（日期冲突时：同一现场同一批受害者，报道日期差 1–3 天
  判同一件事，取事发日，不按「间隔超阈值」拆两起）。
- **月度归属按事发日**，不按发稿日。
- 坐标：缺坐标时按 `Admin1 质心 > 地名 > 国家代表点` 三级兜底，并**标注精度四档**
  （city / district / region / country）。落点带虚化环，**讲解时不要说成「精确落点」**。
- 配点后必须校验**落点是否在它声明的国家内**（用真实国界多边形判定，容差约 0.6°）。
