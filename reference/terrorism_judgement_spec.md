# 判定与编码规范

> 本文件是**判定层**的依据。判定层只做一件事：把采集到的新闻候选行，
> 按下面这套标准判成「是不是恐怖袭击事件」，并编码成固定字段。
>
> 判定层不改采集层。判错了回来改这里，不回去改抽取。
>
> 三段内容：**一、什么算恐怖袭击**（判定）｜**二、字段怎么填**（编码）｜
> **三、机器能判到哪、剩下的必须人判**（边界）

---

## 一、判定标准

### 1.1 五条必选条件（全部满足才算）

| # | 条件 | 含义 |
|---|---|---|
| 1 | **实施主体是非国家行为体** | 不是政府军、不是警察、不是国家机器 |
| 2 | **主观故意** | 意图造成人员伤亡、重大财产损失、公共设施损坏、社会恐慌或社会秩序混乱 |
| 3 | **使用暴力或以暴力相威胁** | 爆炸、武装袭击、劫持人质等；含对人的暴力（伤亡）和财产的暴力（破坏交通枢纽、袭击能源设施） |
| 4 | **与政治目的相关** | 通常涉及推翻政权、改变政策或实现社会控制 |
| 5 | **对象为平民或非战斗状态军警** | 往往通过主动发起攻击获得战术优势 |

### 1.2 两条补充条件（满足其一即可计入，前提是不违背五条必选）

| # | 条件 | 说明 |
|---|---|---|
| A | 实施主体是**联合国或所在国政府认定的恐怖组织/恐怖分子** | 名单见附录 D（本仓库未收录，需另附）。**缅甸无人机袭击的性质待定** |
| B | 事件**被所在国政府直接认定为恐怖袭击** | 典型：美国、加拿大、澳大利亚采集中标为类型 7 的种族、性别、白人至上等议题的事件 |

> 补充条件 B 的意义：有些事件从客观要件看不完全符合（例如施害者动机是种族仇恨而非政治目的），
> 但所在国政府已定性为恐怖袭击 —— 这类按 B 计入，并在备注注明「依所在国政府定性」。

### 1.3 六类事件类型（人工定案字段）

| 值 | 含义 | 是否计入事件总数 |
|---|---|---|
| 1 | 确定属于恐怖袭击事件 | 计入 |
| 2 | 恐怖分子与安全部队交火 | 视条件 1/5 判定，见下 |
| 3 | 因袭击者身份不明而无法确定 | 不计入，留待补充 |
| 4 | 武装组织之间的交战 | 不计入 |
| 5 | 确定不属于恐怖袭击 | 不计入 |
| 6 | 其它 | 不计入 |

**类型 2 的处置**：恐怖分子主动袭击安全部队 → 满足条件 5（非战斗状态军警）→ 计入类型 1。
双方交火且安全部队处于战斗状态 → 计入类型 2，不计入事件总数。

## 二、字段编码

### 2.1 序号 / 事件 ID

两种并存，用途不同：

| 字段 | 位数 | 格式 | 示例 |
|---|---|---|---|
| 序号 | 10 位 | `yyyymmdd` + 2 位当天顺序 | `2024051601` |
| 事件 ID | 12 位 | `yyyymmdd` + 4 位当天顺序 | `199307250001` |

同一天第 1、2、3 起事件依次为 `...01`、`...02`、`...03`。

### 2.2 国家

用标准全称，不用缩写。**本数据库涉及 50 个国家：发达国家 12 个，发展中国家 38 个。**
编码顺序按国家名称汉语拼音首字母排序，首字母相同则顺次比较下一位。详见附录 2（本仓库未收录）。

### 2.3 年 / 月 / 日

公历，三个独立数字字段。

- 日期不详时，按来源给出的时间范围取适当值，**并在备注说明**。
- 只知「发现之前被绑架者尸体」的，记录**尸体发现时间**。

**GTD 口径（参考）**：具体日期不明确时，缺失部分用 `0` 代替，
并在「近似日期」字段记录大致范围。例：只知月份 → 日为 `0`，近似日期写「1978年6月」；
连月也不知 → 近似日期写「1978年上半年」。

**持续事件**：超过 24 小时记「扩展事件」= 1，并记录解决日期（人质获释/被杀/救援成功）；
不足 24 小时记 0。

**事件切分**：同一事件含不同活动、发生在不同时间或地点 → 视为**独立事件**。
例：今天爆炸、明天又一起袭击，两者有明确时间差 → 记两起。

### 2.4 地点

记录到目标国**最详细的行政区划**（省/州/市/县/乡镇）。

1. 行政区划名用**当地官方语言原文**，不翻译。
2. 存在地缘争议或区划变更的，按**当前实际区划**记录，备注注明历史名称与变更。
3. 恐怖分子跨境作案 → 记录**恐怖袭击发生地**，不是策划地。

### 2.5 死亡 / 受伤人数

除了数字，还允许三个非数字值：`不详`、`数人`、`0`。

**绑架事件**

| 情形 | 死亡 | 受伤 |
|---|---|---|
| 报道未记死亡、无后续跟进 | `不详` | — |
| 报道未提受伤、无后续跟进 | — | = 人质人数 |

**其它事件**

| 情形 | 填法 |
|---|---|
| 明确未造成伤亡 | `0` |
| 有死亡证据但人数不明/只写「数人/多人」 | `数人` |
| 「至少 X 人」 | `X` |
| 「在 Y 人左右」 | `Y` |
| 区间（如 1-2 人） | 取最低值 `1` |
| 涉失踪 | 失踪人数计入**受伤** |

**四类冲突处理**

1. 一手信源 vs 二手信源数字不同 → 以**一手**为准
2. 有后续跟踪报道 → 以**最新**为准
3. 明确还有伤亡但人数不详 → 记**目前已知**数字
4. 政府当局与恐怖组织均报 → 取**数据更全**的一方

**统计口径**：所有直接因该事件死亡/受伤的人 —— 平民、军警、袭击者**全部计入**。
若只有受害者数据没有袭击者数据 → 只记受害者；
若只有袭击者数据没有受害者数据 → 只记袭击者。

### 2.6 袭击方式（8 类，**有优先级**）

按下列顺序，多类并存时取**最靠前**的：

| 序 | 类别 | 定义 |
|---|---|---|
| 1 | 暗杀 | 以杀害特定的、显著的个人为主要目的（高级军官、政府官员、名人），常秘密进行 |
| 2 | 武装袭击 | 用枪械、火器、燃烧物、锋利工具（刀具）造成伤亡。**不含**拳脚、石块、木棍等非致命武器 |
| 3 | 爆炸袭击 | 用爆炸物造成伤害 |
| 4 | 绑架 | 以绑架人员为主要目的，为交换/政治让步/扰乱活动，通常转移他处长期关押 |
| 5 | 劫持 | 通过公开控制人质达到政治目的，发生在目标地点、控制时间较短 |
| 6 | 攻击基础设施 | 针对建筑物/设施/基础设施（铁路、石油管道、政府建筑等），人员伤亡是附带结果 |
| 7 | 非武装袭击 | 用非武器方式（拳脚）造成伤亡，**含**化学、放射性等非传统武器 |
| 8 | 不详 | — |

**两条判定细则**

- 「利用爆炸进行暗杀」→ 记**暗杀**（1 优先于 3）
- 「爆炸物 + 火器/燃烧物」→ 记**武装袭击**（2 优先于 3）
- 警察被枪杀但无证据表明是特定选中的高级人物 → **武装袭击**，不是暗杀

### 2.7 袭击武器（9 类，**多武器全记**）

| 序 | 类别 | 含 |
|---|---|---|
| 1 | 生化放核武器 | 生物、化学、放射性、核 |
| 2 | 枪支武器 | 手枪、步枪、其它枪型、未知枪型 |
| 3 | 爆炸物武器 | 地雷、手榴弹、IED、TNT、邮件包裹炸弹、人体炸弹、车载炸弹、投射炸弹（火箭/迫击炮/RPG/导弹）、遥控/定时爆炸装置、其它、未知类型爆炸物 |
| 4 | 燃烧武器 | 燃烧弹、燃烧瓶、火焰喷射器、汽油/酒精 |
| 5 | 近身攻击武器 | 拳脚、钝器（棍棒/石块）、刀具等尖锐物、绳索等勒杀工具 |
| 6 | 交通工具袭击 | 驾车冲撞、飞机冲撞（**不涉及爆炸物**） |
| 7 | 新兴袭击武器 | 无人机、电磁波等 |
| 8 | 其它类型武器 | — |
| 9 | 不详 | — |

**三条特别规则**

- **无人机**：只要涉及无人机，**一律记「新兴袭击武器」**。
  （原文先给了按载荷分类的细则，随后统一改为「涉及即记新兴」——以统一规定为准。）
- **交通工具**：单纯冲撞 → 交通工具袭击；车上装爆炸物引爆 → 爆炸物武器。
- **多武器**：袭击者明确使用多种武器时**全部记录**，不取优先级（与袭击方式不同）。

### 2.8 袭击者

实施主体，包括组织和个人。

- 填写的是**被联合国和相关国家政府认定的、所在国的**恐怖组织/个人
- 报道未说明身份 → 填 `恐怖分子/组织`
- 有详细介绍 → 填**全称**
- 名单见附录 D（本仓库未收录）

### 2.9 事件摘要

简短叙述，需含：时间、地点、袭击者、方式、目的、后果。

> 示例：2024年1月29日夜间，俾路支解放军（BLA）对俾路支省 Kachhi 区 Mach 镇的
> 边防部队总部进行了炸弹袭击，造成 5 名武装分子和 2 名铁路警察人员死亡，另有 4 人受伤。

### 2.10 事件类型

见 1.3。**六类，人工定案。**

### 2.11 备注

记录不确定性、多信源差异、特殊背景，**保留编码判断依据**。

多条按字段顺序依次编号：

> 1. 所记录的死亡人数为最低死亡人数；2. 袭击方式存疑；3. 袭击者身份未知……

### 2.12 信息来源

至少一个可信来源（官方媒体新闻网址优先）。

- 优先填**原始报道网页链接**
- 无一手信源 → 填汇总平台（如 SATP）涉及该事件的**最详细页面**链接
- 目的：可追溯

## 三、机器能判到哪

这一节是给自己看的，别把机器的判断当定论。

### 3.1 机器可以初判的

| 条件 | 机器怎么做 | 可靠性 |
|---|---|---|
| 条件 1 非国家行为体 | 识别施害者是不是军警/政府；`extract_events.STATE_FORCE` | 中。反政府武装算非国家，但难与「政府支持的民兵」区分 |
| 条件 3 使用暴力 | 袭击方式词表匹配 | 高 |
| 条件 5 对象为平民/非战斗军警 | 受害者词表匹配 | 中 |
| 条件 4 政治目的 | 关键词（推翻/独立/建立政权…） | **低**。新闻报道常不写动机 |
| 补充 A 认定组织 | 组织名单匹配 | 高（有名单时） |
| 补充 B 政府定性 | 「被认定为恐怖袭击」句式 | 中 |

### 3.2 机器判不了的（必须人判）

- **条件 2 主观故意** —— 只能从行为推断，无法从文本确认
- **条件 4 政治目的** —— 报道里不写，写了也常是记者的推断
- **事件类型 2 vs 1 的区分** —— 交火时谁先动手、安全部队是否处于战斗状态
- **缅甸无人机袭击** —— 性质待定，不预设
- 所有输出为 `待人工复核`

### 3.3 输出的三档

| 档 | 含义 | 处置 |
|---|---|---|
| `判定=计入` | 五条必选全满足，或补充条件成立 | 进台账 |
| `判定=存疑` | 部分条件机器无法确认 | 进人工队列，附未确认条件 |
| `判定=排除` | 明确不满足某条必选 | 留档，不进台账 |

### 3.4 首轮实测（2026-11-22，13,120 行候选）

```
排除 11,992 ｜ 存疑 862 ｜ 计入 266
计入 266 条里：有日期 206 ｜ 有国家 261 ｜ 有死亡数 62 ｜ 有组织 144
```

**判定器加硬门槛之前是 790 条「计入」，其中混着大量军工新闻。**
原因：「attack / strike / bomb」这些词在军工报道里满地都是。
加了「必须出现具体伤亡或实体破坏」之后降到 266，那 524 条是噪音。

### 3.5 现在还不能用的地方

266 条里有三类明显问题，都是**上游的**，不是判定的：

1. **国家判错。** semafor.com 贡献 46 条，且其中 9 条判成「美国」——
   它是美国媒体，正文里必然出现 Washington / New York。
   抽取层的模板地名剔除挡不住这种「正文正常提及本国」的情况。
2. **旧闻混入。** justearthnews.com 有 2016、2017 年的报道。
   feed 里带了历史文章，采集时没有按发布时间过滤。
3. **正文抽取残留。** lowyinstitute.org 的正文开头仍是标题重复，
   因为它的正文块句末标点占比够，逃过了句子比率检查。

这三条都不该在判定层修。判定层的数据来源质量决定它的上限。

## 四、与 19 列模板的映射

19 列是**对外交付格式**（老师模板），本规范是**内部判定与编码标准**。
两套字段并行，不互相替换。

| 19 列 | 来自本规范 |
|---|---|
| 事件摘要 | 2.9 |
| 国家 | 2.2 |
| 年份 / 月份 / 日期 | 2.3 |
| 地点 | 2.4 |
| 死亡人数 / 受伤人数 | 2.5 |
| 袭击方式 | 2.6 |
| 袭击武器 | 2.7 |
| 袭击者 | 2.8 |
| 信息来源URL | 2.12 |
| 置信度 | 判定层自己算（要素齐全度） |
| 审核状态 | 人工复核后改 |
| 备注 | 2.11 |
| 采集人/组别、录入日期 | 系统填 |
| 负责人/组织、关联知识点 | 留空，人工环节产物 |

**本规范有而 19 列没有的**：序号、事件 ID、事件类型、扩展事件标记、近似日期 ——
这些存在判定层的独立表里，导出 19 列时丢弃。
