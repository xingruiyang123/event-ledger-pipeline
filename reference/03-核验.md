# S3 · 核验（日期、可核性、三种结论）

> 这一段决定台账能不能被追问。两个最常见的塌方：**月份判错**、**把「渠道不通」写成「未报道」**。

## 一、月份只认 published_time（最凶的坑）

⚠️ **检索 API 的日期过滤不约束内容发布时间，只影响排序/召回。**
实测：限定某个时间窗检索，返回结果里混进两个月后的事件，甚至当月的「下个月」事件。

**唯一可信的四种日期来源，按优先级**：

| 顺序 | 来源 | 提取方式 |
|---|---|---|
| 1 | `<meta property="article:published_time" content="...">` | 正则 |
| 2 | JSON-LD `"datePublished"` | 正则 |
| 3 | URL 内嵌日期（`/2026/07/02/`） | 正则 |
| 4 | 标题日期 | 正则 |

**四条一起用**，任一条命中即可定月份；冲突时以 meta 为准。

⚠️ **站点「当期日期」污染**：某报每页页头都印当天日期，按正文日期判定会把当期文章
误判成最新月份。**必须用 meta，不用页面可见文本。**

```bash
python scripts/gate_date_published.py 候选池.jsonl --month 2026-07
```

## 二、每行的结论只能是三种

| 结论 | 含义 | 能不能当证据 |
|---|---|---|
| **找到** | 拿到原文，事实与要素齐全 | 是 |
| **未找到** | 检索过该源/该时段，确实没有 | 是（弱证据：该源没报） |
| **渠道不通** | 索引未覆盖 / 反爬 / 付费墙，取不到正文 | **不是** |

**「渠道不通」严禁记成「未报道」。** 前者说明我们没看到，后者是事实主张。

交付样本：「Vanguard 站内只索引到某年某月，当月内容取不到 → 渠道不通，不核查」。

## 三、URL 可核性（台账的命门）

对台账内每条 URL 做实测，四个判定分开：

| 判定 | 含义 |
|---|---|
| 真实可打开 | 200 + 正文含事件要素 |
| 无法判定 | 403 / 401 / 正文过薄 / 超时 / 浏览器错误页 —— **不等于编造** |
| 编造 / 已删除 | 只有 **404** 才算 |
| 聚合链 | `news.google.com` / yahoo / msn → **不算信源** |

**必须把「无法判定」的原因分类计数**（403 多少条、正文过薄多少条、超时多少条）。
一句「39% 无法判定」毫无信息量；「17 条 403 + 16 条正文过薄 + 7 条超时」才能决定下一步。

## 四、URL 整改（可核性是可以修好的）

按优先级四步，每步都要复测对比：

1. **聚合链 → 真实出版商 URL**（27 条全部替换，聚合链归零）
2. **单源 → 补第二/第三源**（尤其只引一家分析机构的行，补通讯社或本地媒体）
3. **死链 → 补证或按证据不足处理**（不许留着当有效信源）
4. **区分同机构异域名**（`trtafrika.com` ≠ `trtworld.com`；
   `nst.com.my` 马来西亚 ≠ `straitstimes.com` 新加坡；
   `abcnews.com.ng` ≠ `abcnews.go.com`）

实测有效：可核打开率 60% → **81.5%**，零可核信源事件 16 → **0**。
**验收标准写死**：每一条事件至少 1 条核验通过的网址。

## 五、交叉核验派子代理（并发，别串行）

按**地区/主题**拆 5–7 组，同一条消息里并发派出。每个 brief 必须含：

1. 逐条清单：编号（=表格行号）/ 国家 / 日期 / 地点 / 关键事实 / 现有信源域名
2. 候选源池：名称 + 主域名 + 等级，按地区给 6–9 家优先名单
3. 硬性要求原文照抄：
   - **绝对不许编造或推测 URL**，只能返回检索结果里实际出现的链接
   - 必须是该源**自有域名**，排除聚合站与转载站
   - 每条结果给证据：标题 + 能证明是同一事件的关键词
   - **「没找到」是完全可接受的结论，编造不可接受**
   - 同机构不同站点要分清
   - **易混淆提醒**：逐个事件点出高频重名旧事（同名人物早年已死、同名地点历年有旧案）
   - 用 `allowed_domains` 做站内检索为主
4. 返回格式：编号 → 新增可补录（源｜URL｜标题｜证据｜可靠/存疑）+ 已查无结果的源 + 检索次数

**然后自己抽验 3–5 条最关键的原 URL**，逐项核日期、地名、人数、专有名词拼写。
**不要直接采信子代理的链接。**

## 六、把 AI 定不了的显式交人

单列 `待人工审核.md`，每条四段式：

```
## 第 N 行 · 国家 · 日期 · 地点
- 摘要：（台账原摘要）
- 台账：死亡 X、受伤 Y
- 问题：（具体疑问，要有二选一或三选一，不许写「请核实」）
- 来源：（2–3 个可点链接）
```

「问题」要写成可回答的：`死亡到底是 0、1 还是 4？伤 18 是官方口径，另有 36 伤的宽口径。`
不写「请核实伤亡数字」—— 那种话对方没法回答。
