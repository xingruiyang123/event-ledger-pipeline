# S0 · 口径先立（在碰任何数据之前）

> **为什么必须先做**：同一批候选事件，一天内算出 67 和 35 两个相反的「计入」数，差 32 条。
> 根因不是数据，是同一时期并存了多套判定规则。**先立口径，再碰数据。**

## 一、三份文档，缺一不可

| 文档 | 回答什么 | 必须产出 |
|---|---|---|
| **定义** | 这件事按谁的标准算 | 委托方原文（题面/教师/甲方标准）逐字抄录 + 字数校验 |
| **判据** | 怎么一步步判成二值 | 判定链（见下） |
| **计数** | 一次行动打多个点算几件 | 拆分合并判定链 + 距离/间隔阈值 |

三份合一为一个 `口径.md`，文件头写明 **版本 + 生效日期 + 废止清单**。

## 二、判定链（四步，任一步出结果即停）

| 步 | 判断 | 结果 |
|---|---|---|
| **0** | 硬门槛 M0：实施主体是否为国家／政府力量 | 是 → **不计入** |
| **1** | 反证 N1–N6：是否命中任一（私人纠纷 / 索财 / 事故 / 双方已交战 / 反恐执法本身 / 汇总条目） | 是 → **不计入** |
| **2** | 正面判据 P1–P7：是否命中任一 | 是 → **计入** |
| **3** | 兜底：以上都不命中 | **不计入**（定义未满足） |

**硬性要求**：
- 判定结果**只有两个值**。没有「待定」、没有「推定」、没有「证据不足单列」。
- **「不计入」必须写明落在哪一步**：M0 排除 / 反证 N# / 兜底。三者在统计上分开记，
  不许合并成一句「不符合标准」—— 分开记才能看出机制是在哪一层误杀的。
- **反证与官方定性冲突时，官方定性优先**，事故解释降为「争议记录」随条目保存。

## 二之二、「袭击军警算不算恐袭」——必须有明确答案，不能留给人工

这是实践中最常卡住的一条。不同口径给相反结论，导致同一批数据两次算出不同条数。

**本 skill 采用的判定（从真实交付台账提炼，可自动执行）**：

| 谁打谁 | 性质 | 进台账 | 计入伤亡统计 |
|---|---|---|---|
| 非国家武装/恐怖组织 → 袭击**平民、民用设施** | 恐怖袭击 | ✅ | ✅ |
| 非国家武装/恐怖组织 → 袭击**军警、检查站、哨所、军事基地、巡逻队** | **恐怖袭击** | ✅ | ✅ |
| 国家力量 → 打击武装分子（清剿、空袭、抓捕） | **反恐行动** | ✅（作对照） | ❌ |
| 国家力量 → 袭击平民 | 国家暴力 | ✅（作对照） | ❌ |
| 武装组织 ↔ 武装组织 交火 | 交战 | ✅（作对照） | ❌ |
| 犯罪集团 / 帮派 / 贩毒卡特尔 | 非恐袭 | ❌ | ❌ |
| 社区、民族、部落、农牧民冲突 | 非恐袭 | ❌ | ❌ |

**为什么袭击军警算恐袭**：委托方台账的实际处理就是这样——「ISSP 伏击军事巡逻致 16 士兵死」
「海岸警卫队哨所遭 VBIED 袭击」都标为「性质：恐怖袭击」并计入。
判断的分界不是「目标是不是军人」，而是**「实施者是不是非国家行为体」**。

**为什么这能自动判**：UCDP 的 `deaths_a` / `deaths_b` 对应 `side_a` / `side_b`，
据此可算出「政府方伤亡」与「非国家方伤亡」：

- 政府方 0 死、非国家方有死 → 政府主导打击 → **反恐行动**（保留、不计入）
- 政府方有死、非国家方 0 死 → 非国家方单方面袭击 → **恐怖袭击**（计入）
- 双方都有死 → 交火 → 保留作对照，不计入

不需要人工逐条看，规则就能跑完。


## 二之四、三条容易判错的情形（实测踩过）

### ① 拉美区域的「单方面暴力」多半是帮派凶杀，不是恐袭

UCDP 把帮派/卡特尔杀人也记为 type=2「单方面暴力」。2026-07 实测：

| 国家 | 条数 | 行为体 | 摘要样貌 |
|---|---|---|---|
| 墨西哥 | 183 | Jalisco Cartel | Man found murdered at lookout point |
| 哥伦比亚 | 162 | XXX100（脱敏） | Le dieron de baja a alias el Flaco |
| 厄瓜多尔 | 31 | Los Choneros | Crimen en Mucho Lote 1 |
| 巴西 | 14 | Comando Vermelho | Man shot dead in front of his wife |

**这些不是恐怖主义**。规则：拉美国家（巴西/哥伦比亚/墨西哥/厄瓜多尔/危地马拉/洪都拉斯/
萨尔瓦多/委内瑞拉/秘鲁/玻利维亚/海地等）的单方面暴力，默认判为有组织犯罪；
除非行为体是政治性武装组织（ELN / FARC / EPL / 光辉道路 / 民族解放军）。

### ② 行为体被脱敏时，用摘要兜底判，不要直接扔给人工

UCDP 会把未确认的行为体替换成 `XXX100` 这类占位符。2026-07 有 140 条因此被搁置，
但这些摘要其实写得清清楚楚（`IS claims killing 17 soldiers`、`Nine civilians killed in an attack`）。

规则：脱敏时按顺序用摘要关键词判——

1. **排除信号优先**：土地/社区/农牧/部落冲突、汇总条目（`Timeline … Terrorist Activities`）→ 不计入
2. **政府行动**：`rescue / repel / manhunt / neutralize / forces killed / airstrike / drone strike` → 保留作对照
3. **武装袭击**：`militants attack / killed by gunmen / killing of X by gunmen / IS claims` → 计入
4. 都没有 → 才交人工判

注意先判「政府行动」再判「袭击」：`Army, Police Rescue Abducted Children` 和
`Police, Vigilantes Repel Attack` 都含 attack 词，但性质是反恐行动。

### ③ 政府军杀平民（deaths_a=0 且 deaths_b=0）不是恐袭

缅甸「Junta Drone Attack Kills Two Civilians」、苏丹「Sudanese army drone strike kills civilians」
—— 双方战斗人员都没死、只有平民死，`deaths_a=0` 且 `deaths_b=0`。

早前版本落到「有平民死亡就计入 P4」，把政府军空袭算成了恐怖袭击。
规则：分方死亡均为 0 但平民有死亡时，若摘要含 `junta / army strike / airstrike / drone strike /
regime forces / military operation` 等政府军迹象 → 判「保留（国家暴力）」，不计入。


## 二之三、四分类输出（不是三分类）

| 类别 | 含义 | 进台账 | 计入统计 |
|---|---|---|---|
| **计入** | 确属恐怖袭击 | ✅ | ✅ |
| **保留（对照）** | 反恐行动 / 交战 / 国家暴力 —— 有价值的背景，但不是恐袭 | ✅ | ❌ |
| **不计入** | 犯罪、社区冲突、无伤亡等 | ❌ | ❌ |
| **需人工判** | 行为体脱敏、分方死亡缺失，规则判不了 | 待定 | 待定 |

「保留作对照」这一类的存在，是因为委托方明确要求台账里同时保留反恐行动条目
（标注「对照，不计入恐袭伤亡统计」）。**统计口径与收录范围是两件事，不要混。**


  不让自拟的判断直接推翻有独立认定效力的官方定性。

## 三、正面判据必须可操作化到能指向原句

模糊判据是垃圾桶。反例：「大规模针对平民的协同袭击」——「大规模」「协同」都没有量化门槛，
任何拿不准的事件都能塞进去。**逐条改成硬条件，必须全部满足**：

| 条件 | 判定方式 |
|---|---|
| ① 有明确受害对象 | 报道写明被杀/受伤者身份（平民、当时非战斗状态军警、民用设施） |
| ② 有人员伤亡 | 死亡 ≥1 或受伤 ≥3；「多人受伤」不算 |
| ③ 排除私人 / 索财 / 事故 | 报道中无索赎、抢劫、纠纷、事故线索 |
| ④ 有组织的武装暴力形态 | 爆炸 / 武装袭击 / 伏击 / 纵火 / 劫持 / 多目标协同；非孤立斗殴 |

> **主体是否识别，不进这条判据。** 组织不明不影响命中 —— 这正是补这条的目的（否则
> 「真事件但没点名组织」会被整片误杀，本项目实测误杀 15 条）。

## 四、置信度：只做内部评测，不进台账

| 档 | 含义 | 条件（须同时满足） |
|---|---|---|
| A | 多源确证 | ≥2 条**独立信息链** + 事实表述一致 + 伤亡有出处 |
| B | 单源可信 | 1 条权威源（通讯社/官方通报/机构报告）+ 三要素齐全 |
| C | 合理推定 | 事件本身确证 + 关键要素缺一项 + **查过反证且均不成立** |
| D | 证据不足 | 连「是否发生、是否有伤亡」都无法确认 |

- **A/B/C 都计入**，D 落兜底不计入。不因「证据不完美」就不算。
- **判 C 必须写明两件事**：凭什么确证事件本身、查过哪些反证。写不出 → 只能判 D。
  否则 C 会变成「我觉得像」的垃圾桶，等于把废掉的「推定计入」换个名字请回来。
- 置信度**不进台账列、不进对外数字、不进展示材料**。
- 表述把握程度时只说一句「其中 N 条多源确证、M 条单源可信、K 条合理推定」，
  **三档不得相加成另一个「总数」**。

## 五、伤亡赋值（每行必须有数，不许留空）

| 情形 | 记法 |
|---|---|
| 原文给具体数字（含「至少 X」「逾 X」「X 余」） | 取该数（至少 5→5；逾 100→100；20 余→21） |
| 模糊量词：数十→50 · 十数→15 · 数→5（dozens→50 · scores→20 · several→5） | 取折算值 |
| **提到有人死亡，但通篇无任何数字** | **记 1** |
| **完全没提死亡** | **记 0** |
| 伤者 | 同规则，独立计算 |
| 「击毙袭击者」 | **不计入死亡**（那是战果，不是受害者） |
| 区间（如 27–32 死） | 取已采用的值，备注写区间 |

## 六、计数单位（一条记录 = 一起可识别的袭击）

判定链按顺序走，前一步有结论不进入下一步：

| 步 | 判据 |
|---|---|
| 1 | **事发地政府的同一性认定**（国家/省/市/地方警方；层级冲突取高一级）→ 直接采纳 |
| 2 | **组织实施方宣称**「同一次行动」→ 计一条，可跨日期与距离（原则上采信，核不了仍采信） |
| 3 | **同一现场 + 同一批具体受害者** → 计一条（命名地点优先，不受距离限制） |
| 4 | **距离与间隔阈值**（默认推定）：距离 ≤ d 且间隔 ≤ t → 一起；任一超出 → 两起 |
| 5 | 手法签名：独具特色者属微强证据；普通手法相同只用来找候选，不作判据 |

**关键定义**：
- 同一现场 = 同一命名地点（同建筑/同路口/同村组/同营地）；名称不同或描述模糊才用距离兜底。
- 间隔 = 上一次**结束** → 下一次**开始**；不是持续时间。持续 30 小时的围攻算一起。
- 多日事件按起止区间记录，不按天拆。

**默认阈值（无宣称、无官方认定、非同现场时才启用）**：

| 参数 | 默认 | 性质 |
|---|---|---|
| d0（同一现场兜底） | 250 米 | 实测不同命名地点可近至 355 米，取更保守值 |
| d（同一起推定） | 15 公里 | v1.0 默认，扩样后校准 |
| t（同一起推定） | 24 小时 | v1.0 默认 |

> **时空阈值只是默认推定，强证据可双向推翻。** 参数调整要升版本号并记依据。
> 校准方法：取已确认「同一事件」与「不同事件」的对子量距离与间隔，**阈值取两类之间的空隙，
> 不取中间值**；并报敏感性（d 取 10/15/30 km、t 取 12/24/72 h 各是多少条）。
